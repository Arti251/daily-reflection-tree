# Design Write-up

## Approach
I designed a deterministic reflection system based on three psychological axes.

## Tree Design
The tree flows sequentially:
Axis 1 → Axis 2 → Axis 3 → Summary

## Question Design
Each question captures a thinking pattern, not performance.

## Branching Logic
Each option maps to a fixed next node.

## AI Usage
AI was used for brainstorming questions, but final structure was manually refined.

## Guardrails
- No free text inputs
- No runtime AI
- Fixed mapping between nodes

## Improvements
More depth in branching and refined summary logic.
