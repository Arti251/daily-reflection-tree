# Daily Reflection Tree – DT Assignment

## Overview
This project implements a deterministic reflection system based on three psychological axes:
- Locus of Control
- Contribution vs Entitlement
- Radius of Perspective

## How it works
The system asks structured questions with fixed options.
Each answer maps to signals, and a final summary is generated.

## Deterministic Design
- No randomness
- No AI at runtime
- Fixed branching logic
